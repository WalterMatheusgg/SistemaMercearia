# GitHub About — SistemaMercearia

Descrição, endereço e tópicos para apresentar a Loja Ferragens com o mesmo padrão dos outros repositórios do portfólio.

## Description

🔩 Gestão de loja de ferragens com Java 21, Spring Boot 4, Angular 22 e PostgreSQL. Estoque, vendas, compras, caixa e relatórios.

## Website

https://loja-ferragens.vercel.app

Esta URL apresenta a versão de **homologação**. A loja ainda não está homologada para operações comerciais contínuas.

## Topics

`java` · `spring-boot` · `angular` · `typescript` · `postgresql` · `docker` · `fullstack` · `gestao-de-estoque` · `point-of-sale` · `store-management`

## Como aplicar

No Codespace autenticado na conta proprietária, primeiro sincronize a branch `main`, depois execute o script:

```bash
git switch main
git pull --ff-only origin main
bash scripts/configurar-github-about.sh
```

Ou abra o [repositório no GitHub](https://github.com/WalterMatheusgg/SistemaMercearia), clique na engrenagem de **About**, preencha **Description**, **Website** e **Topics**, e salve.

O comando altera apenas metadados do repositório; **não altera a visibilidade**, usuários, permissões ou dados da Loja.
